# Island

A small procedural 3D island you can walk around, in a single `index.html` with no dependencies and no asset files.

- Raw WebGL2: shadow mapping, PBR-style materials, procedural textures, water with sky reflection, clouds, fog, bloom
- Pier with a moored boat, hut on stilts, lighthouse, palm grove, hill, gulls
- Four times of day (golden hour, day, dusk, night) with an optional auto cycle
- Procedural audio: surf, wind, footsteps, gulls
- WebXR mode for headsets such as Meta Quest

## Controls

| | |
|---|---|
| Phone | left thumb moves, right thumb looks |
| Desktop | WASD, mouse, Shift to run, Space to jump, T for time of day, Y for auto cycle, Esc to release the cursor |
| VR | left stick moves, right stick snap-turns, right trigger or A changes time of day, B toggles auto cycle, X toggles sound |

## Running

Open `index.html` from any HTTPS address. VR needs HTTPS and a WebXR browser.
